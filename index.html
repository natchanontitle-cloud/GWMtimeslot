ตรวจตารางเวลานัดหมาย PS

ลากไฟล์ Excel มาวางที่นี่ — ไฟล์ตั้งค่านัดหมาย (export จากระบบ) และ/หรือ ไฟล์ RSM (Store_Name / Region / RSM) ระบบแยกให้เองว่าเป็นไฟล์ไหน

เริ่มต้นใช้งาน

อัปโหลดไฟล์ Excel 2 ไฟล์ (ลากมาวางหรือกดปุ่มด้านล่าง เลือกพร้อมกันทีเดียวได้)
⬜ 1. ไฟล์ตั้งค่านัดหมาย
export จากระบบ (ข้อมูลการนัดหมาย)
⬜ 2. ไฟล์ RSM (ไม่บังคับ)
Store_Name / Region / RSM · ชีต RSM1, RSM2
ไฟล์ถูกอ่านในเบราว์เซอร์นี้ — จะขึ้นเว็บให้คนอื่นเห็นก็ต่อเมื่อกด ☁️ แชร์ให้ทุกคน · ไฟล์ RSM จะถูกจำไว้ในเครื่องนี้ ครั้งหน้าอัปโหลดแค่ไฟล์นัดหมาย

ตารางมาตรฐาน

ใส่เวลาเริ่มของแต่ละช่อง (ช่องละ 30 นาที) คั่นด้วยจุลภาคหรือขึ้นบรรทัดใหม่ เช่น 08:30, 09:00
กด "บันทึกและแชร์ให้ทุกคน" เพื่อให้ทุกคนใช้มาตรฐานเดียวกัน (ใช้ GitHub token เดียวกับปุ่ม ☁️ แชร์)

☁️ แชร์ข้อมูลให้ทุกคน

ระบบจะบันทึกข้อมูลที่โหลดอยู่ตอนนี้ (ไฟล์นัดหมาย + ไฟล์ RSM + ตารางมาตรฐาน) เป็นไฟล์ data.json ใน GitHub — ใครเปิดหน้านี้ก็จะเห็นข้อมูลชุดเดียวกัน ภายใน 1–2 นาที
วิธีสร้าง / แก้ token
  1. github.com → รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: Only select repositories → เลือก repo ของหน้านี้ (ใช้ token เดียวกับ Hub ได้ แค่เพิ่ม repo นี้เข้าไป)
  3. Permissions → Repositories → Contents: Read and write → Update / Generate
